# Changelog

## 1.5.0 — 2026-11-03

Кинозалы Aurora: 13 каналов, афиша, плашки и рекламные ролики.

- **13 киноканалов 20–32**: Кинопремьера, Кинохит, Aurora Cinema, Комедия,
  Боевик, Фантастика, Детектив, Ужасы, Семейный, Наше кино, Легенды кино,
  Ночной сеанс, Сериалы.
- **Фиксированные сеансы 14:00 и 18:00**. Если зритель опоздал, фильм
  продолжается с текущего места.
- **Общая афиша кинозалов**: экран расписания показывает фильмы всех 13
  каналов на ближайший сеанс, с номером канала, жанром, годом, рейтингом и
  описанием. Выбранный канал подсвечен.
- **Анимированная заставка перед сеансом**: девять карточек фильмов
  появляются по очереди, исчезают, затем показывается логотип AURORA TV —
  цикл повторяется до начала фильма.
- **Трёхминутный рекламный блок** в случайной точке фильма (5–70 %):
  анимированные MP4-ролики — туториал по пульту, трейлер 13 каналов и
  заставка AURORA TV. Внизу — таймер «До продолжения», после блока —
  плашка «Продолжение просмотра».
- **Плашки и переходы**: появление/исчезновение с анимацией, прогресс-линия,
  «Сеанс начинается», «Реклама», «Продолжение просмотра», «Титры»,
  «Следующий сеанс», «Сеанс временно недоступен».
- **Спокойная фоновая музыка** — оригинальный сгенерированный трек 62 BPM
  (не сторонняя композиция), плавное появление и зацикливание. Играет в
  афише, ожидании, рекламе и титрах.
- **Синий боке-фон** с падающими бликами и живой анимацией.
- **Ротация без повторов**: каждый сеанс — отдельная позиция каталога,
  вечерний фильм не повторяется на следующее утро; порядок меняется раз в
  месяц.
- **36 public-domain фильмов** с Archive.org: советская классика, нуар,
  комедии, фантастика и киносериалы. Каталог расширяется.
- Кнопки «Смотреть сейчас» больше нет: сеанс начинается автоматически по
  расписанию, а открыть кинозал можно из афиши.

## 1.4.0 — 2026-11-02

Каналы и переключение цифрами, как на обычном телевизоре.

- На главном экране (и в любом разделе Aurora) можно набрать **номер канала**
  на пульте — появится OSD с номером и названием, канал запустится сам.
- **OK** запускает сразу, **BACK** отменяет.
- Новая вкладка **«Каналы»**: эфирное ТВ, список каналов и загрузка
  M3U-плейлиста.
- Встроены официальные бесплатные потоки: НТВ HD, НТВ +1/+2/+4/+7,
  НТВ Право, НТВ Стиль, НТВ Витрина, Россия 1 HD, 360°, 360° Новости,
  2x2, Current Time.
- Для HLS добавлен `media3-exoplayer-hls`.
- **Инфоканал 0**: шесть роликов — трейлер, каналы, туториал по лаунчеру,
  пульт, M3U-плейлист и «что нового 1.4». Порядок случайный, между роликами
  случайные подсказки. Генерируется из `info/episodes.json` скриптом
  `scripts/generate_info.py` (SAPI Irina + Pillow + ffmpeg); есть реальные
  screenrecord-клипы.
- Номера каналов видны в списке; на главном экране подсказка «0–9 — номер».
- **Home переключает** между штатным ТВ со списком каналов и Aurora:
  из Aurora — в ТВ, из ТВ — обратно в Aurora.

## 1.3.0 — 2026-11-02

Видео-хаб без VPN и обходов.

- Новая вкладка **«Видео»**: YouTube через SmartTube и RuTube через штатное
  приложение.
- Кнопка **«Проверить YouTube»** показывает, отвечает ли YouTube у текущего
  провайдера. На Telefunken без VPN ответ отрицательный: TLS/API YouTube
  режется сетью.
- SmartTube определяется и в новой упаковке `org.smarttube.stable`.
- Никакого VPN, прокси и скрытого обхода: если сеть не отдаёт YouTube,
  приложение честно об этом пишет.

## 1.2.0 — 2026-11-02

Универсальная сборка: не только Telefunken.

- Минимальная версия снижена до **Android 5.0 (API 21)**.
- Настройки и Bluetooth работают через стандартные Android-интенты, если
  вендорского пакета нет.
- Wi-Fi: на новых Android, где прямое включение запрещено, открываются
  системные настройки; на старых работает прямое включение/переподключение.
- Сетевой статус совместим с API 21–22 (старый `activeNetworkInfo`).
- На узких/720p-телевизорах список приложений переключается на 4 колонки.
- Расширен список ТВ-пакетов и названий для автоопределения кнопки «ТВ».
- Добавлены `uses-feature` для Wi-Fi/Ethernet как необязательных.
- Исправлены предупреждения lint для Android 5.0.

## 1.1.0 — 2026-11-02

Исправления после проверки на телевизоре.

- Кнопка **Wi-Fi** больше не открывает вендорский экран «Режим сети» и не
  переключает ТВ на проводную сеть. Вместо этого показывается статус,
  кнопка включения Wi-Fi и переподключение сохранённой сети.
- Добавлен пункт **«Все настройки ТВ»** — главный экран системных настроек.
- **Bluetooth** открывается напрямую, без ошибки «нет такого раздела».
- **«Удалить приложение…»** — список пользовательских приложений с системным
  подтверждением удаления.
- **«Удалить Aurora TV»** — безопасный возврат штатного лаунчера без сброса
  телевизора.
- Убраны нерабочие на этой прошивке пункты «Звук» и «Дисплей».
- Разрешения `ACCESS_WIFI_STATE` и `CHANGE_WIFI_STATE` для управления Wi-Fi.

## 1.0.0 — 2026-11-02

Первый публичный релиз.

- Лончер Aurora TV для Telefunken Android TV / Android 7+.
- Главный экран: часы, дата, погода, избранное, плитки приложений.
- Список приложений с 5-колоночной сеткой и скрытием системных приложений.
- Запуск штатного ТВ-приложения через кнопку «ТВ» (выбор приложения).
- Погода MET Norway + Open-Meteo, город по системной таймзоне.
- Медиатека Android 7–9 и SAF-папки на новых версиях.
- Плеер Media3/ExoPlayer для видео и музыки.
- Настройки Wi-Fi, Bluetooth, звука, дисплея, даты/времени.
- Без аналитики, рекламы и трекеров; ограниченные разрешения.
- Проверено на Telefunken TF-LED40S19T2S, Android 7.0.
