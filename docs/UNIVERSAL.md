# Aurora TV Universal

Цель 1.2 — один APK, который запускается не только на Telefunken, но и на
других Android TV, Google TV, Fire TV и ТВ-приставках.

## Что уже сделано

| Что | Как |
|---|---|
| Android 5.0–14 | `minSdk 21`, `targetSdk 34` |
| Цвета на API 21–22 | `ContextCompat.getColor()` вместо `Context.getColor()` |
| Сеть на API 21–22 | старый `activeNetworkInfo` как fallback |
| Настройки | вендорский пакет → стандартный Android-интент |
| Bluetooth | `BluetoothActivity` → `ACTION_BLUETOOTH_SETTINGS` |
| Wi-Fi | `WifiManager`; если Android запрещает — системные настройки |
| Экран приложений | 4 колонки при `screenWidthDp < 900`, иначе 5 |
| Кнопка «ТВ» | расширенный список пакетов и названий |
| Планшеты/боксы | touchscreen не обязателен, leanback не обязателен |

## Как проверялось

- **Telefunken TF-LED40S19T2S**, Android 7.0 (API 24), MT5863 — вживую:
  запуск, HOME, пульт, Wi-Fi-диалог, настройки, удаление приложений.
- Android 5.0/5.1, 8–14 — только сборка и lint; нужны тесты на реальных
  устройствах.

## Что может отличаться на других ТВ

- Вендорские настройки: Aurora пытается открыть `com.cvte.tv.androidsetting`,
  затем стандартный `android.settings.*`. На нестандартных прошивках пункт
  может открыть не тот экран.
- Wi-Fi: на Android 10+ приложение не может включить Wi-Fi напрямую, поэтому
  открывает системные настройки.
- Погода: на Android 5–6 системное хранилище сертификатов может не доверять
  Let's Encrypt/HARICA. Погода в таком случае не загрузится, остальное работает.
- ТВ-приложение: автоопределение эвристическое. Если кнопка «ТВ» открывает не
  то — выберите приложение вручную в настройках Aurora.

## Как помочь

Пришлите:

1. модель ТВ и версию Android (`getprop ro.build.version.release`);
2. что именно не открылось;
3. скриншот экрана.

Это поможет сделать 1.3 действительно универсальной, а не «универсальной на
одном телевизоре».
