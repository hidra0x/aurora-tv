# Сервер управления каналами

В Aurora TV 1.6 встроен небольшой HTTP-сервер. Он запускается вместе с
приложением и позволяет управлять каналами с телефона или ПК в той же
Wi-Fi/Ethernet-сети.

Адрес по умолчанию:

```text
http://IP_ТЕЛЕВИЗОРА:8765
```

IP показан в **Настройки → Система → Сервер управления**. На телевизоре
Aurora TV работает как домашний экран, поэтому сервер обычно доступен
сразу после включения ТВ.

## Веб-панель

Открой адрес в браузере. В панели есть:

- список всех каналов: инфоканал 0, ТВ 1–14, кинозалы 20–32;
- статусы **В эфире**, **Профилактика**, **Обновление**;
- кнопки «Профилактика», «Обновление», «В эфир»;
- запуск профилактики сразу для всех каналов;
- расписание профилактики;
- редактирование расписания в JSON.

Панель обновляется каждые 5 секунд. Данные хранятся в приложении и
переживают перезапуск.

## API

Все ответы — JSON. Авторизации в 1.6 нет: сервер рассчитан только на
домашнюю локальную сеть. Не пробрасывайте порт `8765` в интернет.

### Проверка

```powershell
curl http://192.168.0.3:8765/api/status
curl http://192.168.0.3:8765/api/channels
```

### Профилактика одного канала

```powershell
$body = '{"state":"maintenance","minutes":60,"reason":"Плановые работы"}'
Invoke-RestMethod -Uri http://192.168.0.3:8765/api/channels/20/state `
  -Method Post -ContentType 'application/json; charset=utf-8' -Body $body
```

`minutes` можно заменить на `until` — время окончания в миллисекундах
Unix. Если не указать ни то, ни другое, профилактика ставится на час.

### Обновление канала

```powershell
$body = '{"state":"upgrading","minutes":30,"version":"1.6.1","notes":"Новая сетка вещания"}'
Invoke-RestMethod -Uri http://192.168.0.3:8765/api/channels/20/state `
  -Method Post -ContentType 'application/json; charset=utf-8' -Body $body
```

### Вернуть канал в эфир

```powershell
$body = '{"state":"live"}'
Invoke-RestMethod -Uri http://192.168.0.3:8765/api/channels/20/state `
  -Method Post -ContentType 'application/json; charset=utf-8' -Body $body
```

### Все каналы

```powershell
$body = '{"minutes":60,"reason":"Общая профилактика"}'
Invoke-RestMethod -Uri http://192.168.0.3:8765/api/maintenance/start-all `
  -Method Post -ContentType 'application/json; charset=utf-8' -Body $body

Invoke-RestMethod -Uri http://192.168.0.3:8765/api/maintenance/stop-all `
  -Method Post -ContentType 'application/json' -Body '{}'
```

### Расписание

```powershell
curl http://192.168.0.3:8765/api/schedule
```

`POST /api/schedule` принимает объект `{"schedule": {...}}` или само
расписание. Пример структуры:

```json
{
  "global": { "start": "03:00", "end": "04:00", "note": "Общая профилактика всех каналов" },
  "channels": [
    { "number": 20, "weekday": 2, "start": "04:00", "end": "04:30" }
  ]
}
```

`weekday` — константа Java Calendar: 1 — воскресенье, 2 — понедельник,
…, 7 — суббота.

## Расписание по умолчанию

- **03:00–04:00** — общая профилактика всех каналов.
- **04:00–04:30** — киноканалы 20–26 по одному: пн 20, вт 21, ср 22,
  чт 23, пт 24, сб 25, вс 26.
- **04:30–05:00** — киноканалы 27–32: пн 27, вт 28, ср 29, чт 30,
  пт 31, сб 32.

Расписание — информационное: профилактика не включается сама. Ведущий
запускает её вручную через панель или API, проверяет и затем делает
обновление канала.

## Что видит зритель

- На афише кинозала появляется красная плашка **ПРОФИЛАКТИКА** или
  жёлтая **ОБНОВЛЕНИЕ**, причина и время возврата.
- В кинозале вместо фильма — анимированная плашка профилактики с
  обратным отсчётом. Когда канал возвращается в эфир, плеер сам
  переходит к афише или к текущему сеансу.
- На ТВ-каналах 1–14 в списке появляется пометка, а при попытке
  включить канал показывается сообщение с причиной и временем возврата.
- Инфоканал 0 не затрагивается общим запуском профилактики.

## Ограничения

- Телевизор должен быть включён и Aurora TV должна работать: сервер
  живёт в процессе приложения. После перезагрузки ТВ он поднимается
  вместе с лончером.
- Нет авторизации. Используйте только в доверенной локальной сети.
- Сервер показывает встроенные ТВ-каналы 1–14. Если подключён внешний
  M3U-плейлист, его каналы в панели могут отображаться под встроенными
  номерами.
