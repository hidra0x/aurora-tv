# Голосовое управление Aurora TV с рутированной Алисы

Aurora TV принимает события и команды от демона на Яндекс Станции по HTTP
(`http://<tv-ip>:8765/api/voice/...`). Демон живёт **на Алисе**, поэтому после
разовой установки с ПК работает автономно и стартует при включении станции.

```
Алиса (root)  ── emit.sh / хук ──> events.tsv ──> aurora-voice.sh
                                                        │ HTTP POST
                                                        ▼
                              Aurora TV :8765 ──> VoiceBridge ──> VoiceOverlayActivity
```

## Что показывает экран

| Фаза | На экране |
| --- | --- |
| `LISTENING` | «Внимание. Алиса слушает» + распознанный текст |
| `THINKING` | «Алиса думает» + распознанный текст |
| `ANSWERING` | Текст ответа Алисы |
| `RADIO` | Полноэкранный эквалайзер, подпись «Радио» |
| `TIMER` | Обратный отсчёт и прогресс |

При первом подключении демона на экране появляется мини-инструкция с командами.
Кнопка BACK закрывает оверлей. Если Алиса уточняет канал, варианты можно выбрать
цифрами `1–5` на пульте или сказать «первый», «второй»…

## Команды

- «включи радио» / «выключи радио» — эквалайзер на весь экран; **звук отдаёт Алиса**
  на ТВ через Bluetooth/AUX, Aurora только рисует визуализацию.
- Эквалайзер пульсирует **в такт** (4/4): сильная доля — бас, остальные — середины
  и верха. Темп меняется командами «ритм 128», «быстрее», «медленнее».
  TV не имеет доступа к сэмплам внешнего звука, поэтому для точного попадания
  в долю демон может слать `BEAT` — тогда удары выравниваются по времени.
- «включи мне канал 5», «включи НТВ +1», «включи НТВ плюс один».
- «включи НТВ» — если находятся каналы `НТВ HD`, `НТВ +1`, `+2`, `+4`, `+7`,
  Алиса уточняет вариант.
- «открой телегид» / «программа передач».
- «поставь таймер на 10 минут», «поставь таймер на 1 час», «отмени таймер».
- «что умеешь» — список команд.

## Установка (один раз с ПК)

### Станция rio (root + SSH) — рабочий вариант

Станция не использует ADB для загрузки: root и dropbear уже есть, скрипты
заливаются по SSH. ADB-ключ и `192.168.0.93` здесь не нужны.

```powershell
cd 'C:\AuroraTV'
.\voice\install-from-pc-ssh.ps1 -StationIp 192.168.0.5 -TvIp 192.168.0.3
```

Скрипт копирует `aurora-voice.sh`, `emit.sh`, `install.sh` в `/opt/bin/`
через `scp -O -i C:\lite-kit\work\station_rsa`, запускает установку как root
и создаёт автозапуск `/etc/init.d/S98aurora-voice` (на прошивке rio скрипты
без префикса `S##` не стартуют). Демон живёт в `/data/local/bin/aurora-voice`,
конфиг — `/data/local/etc/aurora-voice.conf`, события —
`/data/local/tmp/aurora_voice/events.tsv`.

Переменные окружения для кастомного запуска:

```powershell
.\voice\install-from-pc-ssh.ps1 -StationIp <IP> -SshKey <PATH> -TvIp <TV_IP>
```

### Универсальный ADB-вариант (для обычных Android-устройств)

```powershell
.\voice\install-from-pc.ps1 -AliceIp <IP> -TvIp <IP>
```

Требует авторизованный ADB. Ставит автозапуск через Magisk `service.d`,
`/etc/init.d` или `/data/local/userinit.sh`.

Для ручной установки прямо на устройстве:

```sh
su
cd /data/local/tmp
sh aurora-voice-install.sh /data/local/tmp
```

Конфиг: `/data/local/etc/aurora-voice.conf`

```sh
TV_IP=192.168.0.3
TV_PORT=8765
POLL=1
AUTO_COMMAND=1      # отправлять команду при событии THINKING
HEARTBEAT=60        # как часто подтверждать подключение
```

Проверка:

```sh
/data/local/bin/aurora-voice status
/data/local/bin/aurora-voice command "включи радио"
/data/local/bin/aurora-voice-emit LISTENING "включи НТВ плюс один"
```

Лог: `/data/local/tmp/aurora-voice.log`.

## Как подключить фазы «слушает / думает / отвечает»

Демон читает поток строк из `/data/local/tmp/aurora_voice/events.tsv`.
Каждая строка — `КИНД<TAB>ТЕКСТ`. Писать туда может что угодно:

- LSPosed-модуль, который хучит метод распознавания/синтеза в приложении Алисы;
- автоматизация (MacroDroid/Tasker/Locale) с действием «shell command as root»;
- внешний сервис или ручная команда `aurora-voice-emit`.

Пример из хука (псевдокод — точные классы зависят от прошивки станции):

```java
// onRecognizeStart(partialText)
exec("aurora-voice-emit LISTENING \"" + escape(partialText) + "\"");
// onThink(finalText)
exec("aurora-voice-emit THINKING \"" + escape(finalText) + "\"");
// onSpeak(answer)
exec("aurora-voice-emit ANSWERING \"" + escape(answer) + "\"");
```

Поддерживаемые `КИНД`:

| КИНД | Действие |
| --- | --- |
| `LISTENING` | фаза «слушает», текст распознавания |
| `THINKING` | фаза «думает», текст; при `AUTO_COMMAND=1` команда уходит на ТВ |
| `ANSWERING` | текст ответа Алисы |
| `COMMAND` | выполнить команду явно |
| `RADIO` | «включи радио» |
| `TIMER` | «поставь таймер …» |
| `RHYTHM` | «ритм 128» — задать темп эквалайзера |
| `BEAT` | выровнять удар (интенсивность в тексте, например `1`) |
| `RESET` | закрыть оверлей |

### Важно про точность фаз

Универсального публичного API у Алисы нет: точки «слушает/думает» есть только
внутри её собственного приложения. На станции rio их не нужно искать в
приложении: собственный `/opt/bin/voice-loop.sh` уже ловит `onPhraseSpotted`
в `/data/quasar/daemons_logs/maind.log` и знает все фазы. Достаточно в его
точках (`handle_wake`, `record start`, `burst + yellow`, `speak.sh`,
`platform back`) писать строки через `aurora-voice-emit`.

LSPosed нужен только если понадобятся внутренние фазы именно приложения
Алисы, которых нет в логе. Для текущей задачи он избыточен.

Без автоматики работают ручной режим и команды через `aurora-voice-emit` —
этого достаточно, чтобы проверить весь экран и все команды на ТВ.

## HTTP API Aurora TV

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET | `/api/voice/status` | фаза, подключение, таймер, текст |
| GET | `/api/voice/help` | мини-инструкция |
| POST | `/api/voice/connect` | `{"connected":true}` — подключить демона |
| POST | `/api/voice/event` | `{"phase":"LISTENING","text":"...","answer":"..."}` |
| POST | `/api/voice/command` | `{"command":"включи радио"}` |
| POST | `/api/voice/select` | `{"index":0}` — выбор варианта |
| POST | `/api/voice/reset` | закрыть оверлей |

Ответ содержит полный снимок состояния, включая `answer` — его можно сразу
отдать в TTS Алисы. Веб-панель `http://<tv-ip>:8765/` содержит тестовые кнопки
всех фаз и команд.

## Диагностика

- **Оверлей не появляется** — проверьте `curl http://<tv-ip>:8765/api/voice/status`
  и что демон подключён (`connected: true`).
- **Алиса не видит ТВ** — проверьте `TV_IP` в конфиге и что порт `8765` открыт.
- **Команда не выполнилась** — отправьте её вручную:
  `aurora-voice command "включи радио"`.
- **Фазы не меняются** — значит хук/автоматизация не пишет `events.tsv`;
  проверьте права и путь файла.
