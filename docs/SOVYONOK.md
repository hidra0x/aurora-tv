# Совёнок — семейство каналов 15–18

Детское семейство Aurora TV после полного ребрендинга. Новое имя, новый
логотип, «новая дирекция» и новая сетка: советские диафильмы-сказки,
наука и английский для детей.

| Канал | Название | Для кого |
| --- | --- | --- |
| 15 | Совёнок | 0–6: сказки и английский |
| 16 | Совёнок Юниор | 2–5: счёт, английский, простые уроки |
| 17 | Мульт-Класс | 6–10: сказки и наука |
| 18 | Тин-Класс | 10–14: английский и технологии |

У каждого канала свой логотип, каталог, расписание, ночной режим и
экран профилактики. Медиатека и жёлтые анонсы общие.

Все каналы работают **с 05:00 до 22:00**, ночью показывают «Спокойной
ночи, дети», живые часы и таблицу следующего дня. Полная утренняя
заставка есть у канала 15; каналы 16–18 начинают эфир с анонса.

## Эфир

- **05:00–22:00** — сказки и уроки английского с анонсами.
- **Анонс перед каждой программой**: жёлтая заставка «Совёнок» →
  надпись «Представляет» → фрагмент из программы → плашка с названием
  и временем, диктор говорит: «Колобок — в два часа дня на канале
  Совёнок» → логотип «Совёнок» → начинается программа.
- **Дневной блок**: 14:00 Колобок, 14:30 Теремок, 15:00 Репка,
  15:30 английский «Приветствие», 16:00 «Цвета», 16:30 «Животные»,
  далее по кругу до 22:00.
- **Логотип в углу** во время программы; на анонсе его заменяет
  полноэкранная заставка.
- **05:00** — утренняя заставка: таблица программы, сигнал, «Трансляция
  скоро начнётся», музыка, три цикла логотипа и трейлер с диктором.
  В трейлере — «новая дирекция» канала. Заставка запускается один раз в
  день; при повторном входе канал сразу показывает анонс.
- **22:00–05:00** — «Спокойной ночи, дети»: часы, дата, таблица на
  завтра и тихая музыка. В 05:00 канал сам возвращается в эфир.

## Программы

### Анонсы

Для каждой программы сгенерирован отдельный жёлтый анонс в стиле
советского детского телевидения. Это **оригинальная** графика «Совёнка»,
а не кадры из «Карусели»: чужой бренд и чужое видео не используются.
В анонсе есть название программы, время и фрагмент; голос произносит
название и время.

### Советские диафильмы-сказки

Оригинальные постановки Aurora TV по русским народным сказкам. Это не
пиратские копии советских мультфильмов: рисунки, анимация и озвучка
сделаны специально для канала.

| Программа | Жанр |
| --- | --- |
| Колобок | сказка |
| Теремок | сказка |
| Репка | сказка |

### Английский с Совёнком

| Урок | Тема |
| --- | --- |
| Урок 1 | Приветствие: Hello, Good morning, Goodbye |
| Урок 2 | Цвета: red, blue, green, yellow, black, white |
| Урок 3 | Животные: cat, dog, bird, fish, bear, fox |
| Урок 4 | Счёт до 5: one, two, three, four, five |

В уроках русские объяснения и английское произношение (голоса
Microsoft Irina и Microsoft Zira), карточки, повторение и мини-квиз.
Урок 4 идёт на канале «Совёнок Юниор».

### Наука и технологии

- «Почему идёт дождь?» — круговорот воды в природе (Мульт-Класс).
- «Как работает интернет?» — сеть, сервер, клиент, IP-адрес (Тин-Класс).

## Копирайт

Классические советские мультфильмы («Ну, погоди!», «Простоквашино»,
«Чебурашка», «Малыш и Карлсон» и другие) ещё защищены авторским правом.
Пиратские копии в канал не добавляются. Легальные варианты:

- оригинальные постановки в советском стиле (сейчас в эфире);
- ранняя советская/российская анимация, перешедшая в public domain;
- фильмы и мультфильмы, которые вы предоставите с лицензией.

Если у вас есть легальные файлы или подписка — их можно добавить в
каталог и на ТВ.

## Файлы и автоматика

Каталог: `app/src/main/assets/kids/catalog.json`.
Видео: `app/src/main/assets/kids/media/` — входят в APK и работают без
интернета. Если в папке приложения на ТВ есть одноимённый файл, плеер
сначала берёт его (удобно для обновлений без пересборки).

Сгенерировать все выпуски:

```powershell
python scripts\make_sovyonok_content.py
```

Только один выпуск:

```powershell
python scripts\make_sovyonok_content.py --only kolobok
```

Заставка, логотип и озвучка:

```powershell
python scripts\make_kids_startup.py
```

Для озвучки используется `scripts/tts_voices.ps1` (Irina/Zira).

## Профилактика

Каналы 15–18 входят в общее расписание профилактики и в спецэфир.
При технических работах показывается фирменный экран канала: его
логотип, надпись «Технические работы», причина, время возврата и
спокойная оригинальная музыка.

Поставить на профилактику на 60 минут (замените `15` на 16, 17 или 18
для других каналов семейства):

```powershell
$body = '{"enabled":true,"reason":"Профилактика канала «Совёнок»","minutes":60}'
Invoke-RestMethod -Uri http://192.168.0.3:8765/api/channels/15/maintenance `
  -Method Post -ContentType 'application/json; charset=utf-8' -Body $body
```

Вернуть в эфир:

```powershell
$body = '{"enabled":false}'
Invoke-RestMethod -Uri http://192.168.0.3:8765/api/channels/15/maintenance `
  -Method Post -ContentType 'application/json; charset=utf-8' -Body $body
```

## Ограничения

- Классические советские мультфильмы не входят в каналы из-за копирайта.
- Уроки английского — начальный уровень, без сложной грамматики.
- Плейлист идёт по кругу; таблица показывает ориентировочное время.
- Время в анонсах — ориентировочное: это дневной блок, а не жёсткая
  сетка. На разных каналах семейства порядок программ отличается.
- Новые выпуски добавляются через каталог и скрипт; все источники
  должны быть легальными.
