# Aurora Cinema — кинозалы

13 линейных киноканалов в Aurora TV, номера **20–32**. Источник фильмов —
**public domain** с Archive.org; Zona и пиратские каталоги не подключаются.

## Как выбирается фильм

Каталог — `info/cinema_films.json`. У канала — список `films` в
`info/cinema_channels.json`.

Каждый месяц порядок фильмов канала перемешивается детерминированно, а
позиция считается отдельно для каждого сеанса:

```text
seed = channel.number * 1_000_003 + year * 100 + month
order = shuffle(channel.films, seed)
slot = ((year * 366 + day_of_year - 1) * 2) % order.size
current = order[slot]          # 14:00
next = order[(slot + 1) % order.size]   # 18:00
```

- В один день разные каналы показывают разные фильмы.
- Вечерний фильм не повторяется на следующее утро: у 18:00 и у завтрашних
  14:00 разные позиции каталога.
- Каждый месяц порядок меняется — даже при 5 фильмах нет ощущения
  одинакового «поезда».
- После титров автоматически запускается следующий фильм; плашки
  «Сеанс начнется», «Реклама», «Продолжение просмотра», «Титры» идут по кругу.

## Афиша

Экран расписания — общий для всех кинозалов. Он показывает фильмы каналов
20–32 на ближайший сеанс: номер и название канала, фильм, год, длительность,
рейтинг и описание. Строки появляются с анимацией, выбранный канал подсвечен.
`OK` открывает кинозал этого канала. Кнопки «Смотреть сейчас» нет: сеанс
начинается автоматически по расписанию, а опоздавший подключается к фильму
с текущего места.

## Заставка перед сеансом

Пока идёт ожидание, на экране циклически показывается афиша:

1. девять карточек фильмов появляются по очереди;
2. карточки исчезают;
3. появляется логотип **AURORA TV**;
4. цикл повторяется до времени сеанса.

Внизу всё время виден обратный отсчёт до начала. Музыка играет непрерывно.

## Рекламный блок

В случайной точке фильма (5–70 % длительности, детерминированно для канала
и фильма) включается **трёхминутный** рекламный блок:

- MP4-ролик «Как пользоваться пультом»;
- трейлер 13 киноканалов;
- заставка AURORA TV;
- плейлист зациклен, внизу — таймер «До продолжения»;
- после блока показывается плашка «Продолжение просмотра», затем фильм
  продолжается с того же места.

Ролики генерируются скриптом `scripts/make_cinema_ads.py` (Pillow + ffmpeg,
H.264 Main, 1280×720, без звука). Фон — `scripts/make_cinema_bg.py`,
музыка — `scripts/make_cinema_music.py` (оригинальный трек, 62 BPM).

## Повторы

Повторы — нормальная часть линейного ТВ. Чтобы они не бросались в глаза:

1. В каждом канале должно быть **10–20 фильмов**, а не 3.
2. Один фильм может идти в разных каналах (например, «Его девушка
   Пятница» — в «Комедии» и «Aurora Cinema»), но с разными плашками.
3. У каналов разные акцентные цвета: премьера — красная, ночной — синяя,
   семья — зелёная и т.д.
4. Каталог пополняется public-domain фильмами; цель — 100+ позиций,
   дальше 200–300. Это не «свежие премьеры», а новые для канала фильмы.

## Медиатека

Кинозалы — эфир по расписанию. Отдельный раздел «Все фильмы» позволяет
выбрать любой фильм каталога и запустить его вне ротации (on-demand).
Это следующий шаг после линейных каналов.

## Добавление фильмов

```powershell
python scripts\fetch_archive_films.py   # найти public-domain MP4 на Archive.org
python scripts\enrich_cinema.py         # описания, советское кино, сериалы
```

Затем фильмы распределяются по каналам в `info/cinema_channels.json`,
JSON копируется в `app/src/main/assets/cinema/`, и APK пересобирается.
Никакого сервера расписания нет: дата считается на телевизоре.

## Профилактика и обновление

Кинозалы управляются через встроенный сервер (`docs/CONTROL.md`).
Канал может быть в состоянии:

- **в эфире** — обычное расписание;
- **профилактика** — вместо фильма плашка с причиной и обратным отсчётом;
- **обновление** — жёлтая плашка «Обновление канала» с версией и заметками.

После окончания профилактики плеер сам возвращается к афише или к
текущему сеансу. На афише канал подсвечивается красным или жёлтым, а
вместо времени показывается «ПРОФИЛАКТИКА» / «ОБНОВЛЕНИЕ».

## Ограничения

- Archive.org может быть медленным; при ошибке показывается плашка
  «Сеанс временно недоступен» и переход к следующему фильму.
- Права public domain зависят от страны; в каталоге есть ссылка на
  страницу Archive.org для каждого фильма.
- Свежие релизы требуют лицензии/легального источника. Zona не
  используется.
- Музыка в APK — оригинальная сгенерированная композиция. Сторонние треки
  (в том числе приложенный пользователем Cult Member) не встраиваются без
  разрешения правообладателя; при наличии прав трек можно заменить.
- Рекламные ролики — собственные анимированные заставки Aurora TV, а не
  чужие рекламные материалы.
