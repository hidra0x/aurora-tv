# Aurora TV — roadmap

## v1.0 — уже готово

- Лончер с HOME-интентом, автозапуск после перезагрузки.
- Главный экран: часы, дата, погода, избранное, плитки приложений.
- Полный список приложений, скрытие служебных системных приложений.
- Медиатека Android 7–9 + SAF-папки, встроенный плеер Media3.
- Настройки ТВ, Wi-Fi/Bluetooth, город погоды.
- Без аналитики, рекламы и трекеров.

## v1.1 — сеть и удаление без сброса

- Кнопка Wi-Fi не открывает вендорский экран «Режим сети» и не переключает
  телевизор на проводную сеть. Показывает статус, включает Wi-Fi и
  переподключает сохранённую сеть.
- «Все настройки ТВ» и прямой Bluetooth.
- «Удалить приложение…» — список пользовательских приложений с системным
  подтверждением.
- «Удалить Aurora TV» — возврат штатного лаунчера без factory reset.
- Убраны нерабочие «Звук» и «Дисплей».

## v1.2 — Universal

- Android 5.0+ (API 21), а не только 6.0+.
- Стандартные Android-интенты настроек вместо жёсткой привязки к CVTE.
- Wi-Fi: прямое включение на старых ТВ, системные настройки на новых.
- 4 колонки на 720p/узких экранах.
- Расширенное автоопределение ТВ-приложения.
- Тесты на Telefunken; нужны тестеры на других моделях.

## v1.3 — видео-хаб

- Вкладка «Видео»: YouTube через SmartTube и RuTube.
- Проверка доступности YouTube у провайдера.
- Поддержка новой упаковки SmartTube `org.smarttube.stable`.
- Без VPN и обходов: если сеть не отдаёт YouTube, показывается причина.
- Проверено: RuTube запускается; YouTube на Telefunken без VPN не грузится
  (TLS/API режется сетью).

## v1.4 — каналы и цифровое переключение

- Набор номера канала на пульте с OSD и автозапуском.
- OK — смотреть, BACK — отмена.
- Вкладка «Каналы» со списком и номерами.
- Официальные бесплатные HLS-потоки (НТВ, Россия 1, 360°, 2x2, Current Time).
- Загрузка M3U-плейлиста для остальных каналов.
- HLS через Media3 ExoPlayer.

## v2.0 — SmartTube + собственный сетевой обход

Цель: запустить SmartTube и смотреть видео без ручного включения VPN/ByeByeDPI.

### Почему не VPN

На прошивке Telefunken TF-LED40S19T2S отсутствует системный пакет
`com.android.vpndialogs`. Любое VPN-приложение (включая ByeByeDPI в режиме VPN)
падает с `ActivityNotFoundException`, потому что Android не может показать
диалог согласия на VPN. Поэтому собственный обход будет **SOCKS5-прокси без VPN**.

### Что войдёт в v2.0

1. **Локальный SOCKS5-прокси внутри Aurora TV**
   - слушает `127.0.0.1:1080` (или резервный порт);
   - принимает соединения от SmartTube;
   - выполняет TLS ClientHello fragmentation: режет первые байты TLS-хендшейка
     на маленькие TCP-сегменты, чтобы DPI не видел SNI;
   - работает как foreground service, статус — в настройках Aurora;
   - автозапуск при включении ТВ (опционально).

2. **Интеграция со SmartTube**
   - определение stable/beta (`com.teamsmart.videomanager.tv`,
     `com.liskovsoft.smarttubetv.beta`);
   - плитка «YouTube» на главном экране: запускает прокси и открывает SmartTube;
   - мастер настройки: SmartTube → Настройки → Общие → Интернет-цензура →
     Использовать веб-прокси → SOCKS5 `127.0.0.1:1080`;
   - проверка статуса прокси и кнопка «Проверить соединение»;
   - обновление SmartTube из официальных GitHub Releases (APK скачивается,
     проверяется SHA-256/подпись, установка — через системный установщик).

3. **Диагностика**
   - проверка DNS, IPv4/IPv6, доступности YouTube API и `googlevideo`;
   - журнал последних ошибок без отправки данных наружу;
   - если простая фрагментация не помогает — выбор стратегии
     (split/disorder/fake) и тест по доменам, как в ByeByeDPI.

### Статус прототипа (02.11.2026)

Локальный SOCKS5 с TLS-фрагментацией уже написан в ветке `v2-proxy`.
Google/GitHub/MET через него работают, но YouTube всё равно уходит в таймаут:
простого split недостаточно для DPI этого провайдера. Следующий шаг — либо
подключить проверенный движок byedpi, либо использовать внешний прокси
(ПК/VPS), либо дожать stable SmartTube 22.38 с proxy-режимом ByeByeDPI.

### Root-путь: экспериментальный, сейчас отключён

Прошивка оказалась `userdebug`: `adb root` даёт root-shell без разблокировки
загрузчика. Технически через root удалось авторизовать ByeByeDPI и включить
**always-on VPN**: `tun0` поднимался после перезагрузки, SmartTube доходил до
экрана входа.

**Но на практике этот вариант оказался небезопасным:** после перезагрузки ТВ
потерял сеть и ADB, а без физического доступа к телевизору это превращается
в проблему. Настройка always-on VPN была снята, ByeByeDPI удалён. Повторять
её без доступа к ТВ и без необходимости не стоит. Скрипты оставлены только
как документация эксперимента.

Для v2 безопаснее локальный прокси внутри Aurora (без always-on VPN) или
внешний прокси на ПК/VPS. `/system` при эксперименте не менялся — только
Secure Settings.

### Ограничения, о которых честно

- Мы не встраиваем обход DRM, платных подписок или пиратских раздач.
- Эффективность обхода зависит от DPI конкретного провайдера; универсальной
  кнопки «работает везде» не существует.
- Приложение не устанавливает сторонние APK молча: Android требует
  подтверждение пользователя (кроме root/device owner).
- SmartTube — сторонний клиент; его работоспособность и условия использования
  зависят от YouTube и автора SmartTube.
